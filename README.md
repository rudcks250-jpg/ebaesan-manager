# 이배산 업무관리 시스템 (Ebaesan Manager)

고깃집 직원 업무관리 웹앱 프로토타입입니다. React + TypeScript + Tailwind CSS v4 + React Router로 구현했으며,
현재 단계는 **localStorage 기반 프로토타입**입니다.

## 실행 방법

```bash
npm install
npm run dev       # 개발 서버 (http://localhost:5173)
npm run build      # 프로덕션 빌드 (dist/ 생성)
npm run preview    # 빌드 결과 미리보기
```

## 테스트 계정

| 구분 | 아이디 | 비밀번호 |
|---|---|---|
| 관리자 | admin | admin1234 |
| 직원(홀) | 김하은 | 12345678 |
| 직원(주방) | 박주방 | 22223333 |
| 직원(시급제) | 이시급 | 44445555 |
| 직원(월급제) | 최월급 | 66667777 |

(직원 비밀번호 = 전화번호 뒤 8자리, 로그인 화면 하단에도 안내되어 있습니다. 최초 로그인 시 비밀번호 변경이 강제됩니다.)

## 구현한 기능

- **로그인**: 이름 + 전화번호 뒤 8자리, 첫 로그인 비밀번호 변경 강제, 동명이인 대응(내부 employeeId 식별)
- **대시보드**: 관리자/직원 화면 분리, 오늘 출근/휴무/근무중 인원, 주간 예정 근로시간, 월간 누적 근로시간, 승인 대기 휴무, 근로시간 미입력 건수, 오늘 근무/퇴근 직원 목록(시간순), 공지사항
- **직원관리** (관리자 전용): 등록/수정/비활성/퇴사 처리, 권한·시급·월급 변경, 비밀번호 초기화, 검색/필터, 카드형 UI
- **스케줄**: 주간 근무표(직원×요일), PC 스크롤 고정 헤더/이름 열, 모바일 가로 스크롤, 셀 클릭 편집, 빠른 일괄 입력, 본인 스케줄 강조, 승인된 휴무 자동 반영
- **휴무신청**: 차주만 신청 가능, 사유 입력, 중복 신청 방지, 관리자 승인/반려(반려 사유 필수), 승인 시 스케줄 자동 반영(기존 근무 있을 경우 확인창)
- **근로시간**: 월간 캘린더, 출근하기/퇴근하기 버튼(자동 시간 기록 및 수정 가능), 수동 입력(자정 넘김 계산 지원), 관리자용 직원별·월별 조회 및 수정, 누락 기록 표시
- **발주관리**: 카테고리(육류/채소/주류/소모품/기타) 탭 + 빈 상태 화면 (상세 기능은 추후 확장)

## 아키텍처

```
UI 컴포넌트 → services/ (비즈니스 로직) → repositories/ (CRUD) → data/storage.ts (localStorage)
```

- `data/storage.ts` 파일만 `window.localStorage`를 직접 호출합니다.
- `repositories/*`는 엔티티별 CRUD만 담당하며 비즈니스 로직이 없습니다.
- `services/*`는 검증, 상태 전이(예: 휴무 승인 → 스케줄 자동 반영), 집계(대시보드) 등 비즈니스 로직을 담당합니다.
- UI 컴포넌트는 `services/*`만 호출합니다.

### 실제 백엔드(Firebase/Supabase 등)로 전환하는 방법

1. `repositories/*.ts` 내부 구현을 REST/Firestore/Supabase 클라이언트 호출로 교체 (함수 시그니처는 유지)
2. `services/authService.ts`의 로그인/해시 로직을 실제 인증 서비스 SDK 호출로 교체
3. `data/seed.ts` 호출부(`main.tsx`)와 `data/mockData.ts` 제거
4. `data/storage.ts`는 더 이상 필요 없으면 제거, 필요 시 캐시 계층으로 유지 가능
5. 컴포넌트/서비스 계층은 수정 없이 그대로 사용 가능 (설계 목표)

## 아직 구현하지 않은 부분

- 발주관리 상세 기능(품목 추가, 수량, 거래처, 단가, 발주 주기, 발주 완료 처리)
- 급여 자동 계산(시급 × 근무시간, 월급 관리)과 근로시간의 연동
- 알림(푸시/문자) 기능
- 실제 백엔드 연동 및 서버 인증

## 핵심 테스트 항목 체크리스트

- [ ] admin / admin1234 로그인 → 대시보드 관리자 화면 확인
- [ ] 직원 계정으로 로그인 → 첫 로그인 비밀번호 변경 모달 확인
- [ ] 직원관리에서 직원 등록 → 신규 계정으로 로그인(초기 비밀번호 = 전화번호 뒤 8자리) 확인
- [ ] 스케줄 화면에서 셀 클릭 → 근무시간 입력/휴무 설정/삭제 확인, PC에서 스크롤 시 헤더·이름 고정 확인
- [ ] 스케줄 "빠른 입력"으로 여러 직원×여러 날짜 일괄 적용 확인
- [ ] 직원 계정으로 휴무신청 → 차주 날짜만 선택 가능한지, 이번 주는 불가한지 확인
- [ ] 관리자 계정에서 휴무 승인 → 해당 직원 다음 주 스케줄에 자동 반영되는지 확인
- [ ] 휴무 반려 시 반려 사유가 직원 화면에 표시되는지 확인
- [ ] 근로시간에서 출근하기/퇴근하기 버튼으로 자동 기록 확인, 자정 넘기는 시간 수동 입력 시 계산 확인
- [ ] 관리자 근로시간 화면에서 직원별/월별 합계 및 미입력 건수 확인
- [ ] 모바일 너비에서 하단 네비게이션(더보기 포함), PC 너비에서 좌측 사이드바 확인
